Two-minute setup

How to add a BMS watch

The fastest and most accurate way is to paste a BookMyShow link. The URL already contains the movie code, theatre code, show date, and session — no need to hunt for IDs by hand.

Back to dashboard
01

Find the movie and showtime

Open BookMyShow, choose your city, then open the movie you want.

  1. 1Movie title. This is what you will see in the watchlist.
  2. 2Date tab. Pick the exact date you want to watch.
  3. 3Theatre card. The name above the showtime buttons.
  4. 4Showtime. Click it to open the seat page.
02

Copy the link from the seat page

After you click a showtime, copy the URL from your browser's address bar.

https://in.bookmyshow.com/movies/hyderabad/seat-layout/ET00521930/ALUC/6296/20261022

  • City hyderabad (or hyd)
  • Event code ET00521930
  • Venue code ALUC
  • Session 6296
  • Show date 22 Oct 2026

Paste the whole URL into New watch → Paste your BookMyShow link. The form fills in the movie title when the URL contains it, plus the event code, theatre code, city, and show date. Seat-page URLs don't contain the movie title, so type that field yourself if it stays blank.

03

Shows not announced yet? Use a time window.

You don't need to guess the exact showtime before BMS publishes it.

  1. Copy the movie page URL instead:
    https://in.bookmyshow.com/movies/hyderabad/jailer-2/ET00521930
  2. Set the show date to the day you want.
  3. Choose Time window and enter the range you'd accept, for example 18:00 to 23:30.
  4. If you don't know when tickets open, choose Start watching now — drop time unknown.
Why a window? A movie can publish 7:00 PM, 9:30 PM, and 11:20 PM shows at different times. A window tells the watch to accept any show in this range instead of forcing a time that isn't on BMS yet. The Scheduled reminder alerts at your drop time; the live BMS availability checker is the next stage and will use this saved window.

On a movie-page link there is no theatre code. Leave Venue code blank to watch any theatre in the city, or add the code if you know it. The Theatre / venue field is just a label; use the real name (for example, “ALLU Cinemas: Kokapet”) so alerts are easy to read.

05

Payment stays in BMS

The handoff opens the show; you choose seats and pay.

🔒
No cards, CVV, UPI ID, or PIN are stored.

This app never asks for payment credentials. A UPI ID on its own cannot authorise a payment anyway — the approval happens in your UPI app with a PIN or biometric. You'll enter payment details directly in BMS or your bank/UPI app, and only you can approve the charge.

In the Telegram alert you'll get the show details and a direct BMS link. In the dashboard, a triggered watch turns amber and shows Open BMS seats. Complete the payment there, then mark the watch as booked.
